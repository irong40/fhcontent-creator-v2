## What Was Built
A standalone Python CLI (`scripts/ollama-grade.py`) that grades a social media post for virality using a local Ollama model (default mistral:7b) as a free pre-filter before content is escalated to Claude. It implements the rubric from the `post-grader` Claude skill (`~/.claude/skills/post-grader/SKILL.md`): 7 scored dimensions with hook strength weighted 50%, a 7-rule voice audit, top-3 fixes, and a `publish_ready` flag at overall >= 8.0. Output is JSON (default) or a markdown scorecard (`--markdown`).

## Key Decisions
- **Model scores, Python arithmetic**: the LLM returns per-dimension 0-10 scores and fix suggestions; the weighted overall score and rule penalties are computed in Python so a 7B model's math never affects the final number.
- **Hybrid rule checking**: mechanical voice rules (em dashes, filler words, filler openers, hashtag count, numbers-as-digits, passive voice) are regex-checked in Python; only contractions rely purely on model judgment. For numbers-as-digits and active-voice, regex and model verdicts are OR'd (fail if either flags). This was added after live testing showed mistral:7b missed 2 of 5 planted violations.
- **Rubric loaded at runtime** from the skill's SKILL.md (Step 3 section extracted by regex) so skill edits propagate without touching this script.
- **No third-party deps**: stdlib only (urllib), so it runs under any Python 3 without a venv — intended to be called from n8n Execute Command nodes and cron scripts.
- **Voice dimension skipped and weights renormalized** when no `--brief` (brand-brief.md) is provided.

## Areas of Concern
- `extract_rubric` regex depends on SKILL.md keeping "### Step 3" / "### Step 4" headings; silently falls back to sending the whole file if the headings change (which includes conflicting markdown-output instructions).
- The passive-voice and numbers-as-words regexes are heuristics; false positives are possible (e.g., legitimate "has been built" in a quote).
- Missing dimensions from the model default to a neutral 5 with no loud warning — could mask a partially-broken model response.
- Weight renormalization when voice is skipped deviates slightly from the skill (which just says "skip and note") — judgment call, not specified behavior.
- No retry on malformed model JSON; exits 2 on first failure.
- Timeout default 120s may be too tight for a cold model load (observed 15s load + ~12s inference warm, but a busy GPU could exceed it).

## Known Limitations
- Dimension score quality is bounded by the 7B model; intended as a triage gate, not a replacement for the Claude post-grader skill.
- Contractions rule is model-judged only.
- `SKILL_PATH` is hardcoded to the user-level skill location; no CLI override.
- Fixes array trusts the model for exactly-3 items; fewer are passed through silently.
