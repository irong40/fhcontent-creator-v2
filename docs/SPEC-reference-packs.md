# SPEC: Reference Packs — competitor-derived style briefs for generation prompts

**Status:** Approved for implementation (branch `feat/reference-packs`)
**Date:** 2026-07-24
**Origin:** Marcus YTA faceless-channel tactic review (2026-07-24 session). The one tactic worth adopting: never prompt the model cold — feed it a *reference pack* distilled from a niche's proven-viral competitors (title patterns, hook patterns, script structure, thumbnail style), then generate original content in that style.
**Code map:** produced by 4-reader ultracode fan-out 2026-07-24; file:line refs below are from that map and were verified against the live repo at commit `d4772c6`.

---

## 1. Goal

Per-persona **style briefs** — short, distilled descriptions of what works in that persona's competitive niche — injected into topic-generation and content-generation prompts, plus a **local ingest script** that builds the brief from competitor videos (yt-dlp transcripts + metadata + Claude vision on thumbnails + Claude distillation).

Non-goals (v1): passing reference *images* into the thumbnail generation ladder (see §8 Deferred), newsletters, podcasts, lectures, carousel slide prompts.

## 2. Design principles (non-negotiable)

1. **No-op by default.** Every prompt is **byte-identical** for personas with no `style_brief` (NULL/empty). This is the established invariant (`winnersBlock` prompts.ts:150-159, `voiceBlock`, `image_subject_constraint` prompts.ts:314) and `prompts.spec.ts` asserts prompt contents for unconfigured personas.
2. **Zero route changes.** `daily-topic` selects `personas.*` (route.ts:48-52) and `content-generator` joins `personas(*)` (route.ts:67-74) — a new persona column rides along automatically. All injection lives in `src/lib/prompts.ts`.
3. **Patterns, never wording.** The brief teaches *structure* (title shapes, hook mechanics, pacing beats, thumbnail composition), never copyable sentences. The distillation prompt enforces this; the injection block restates it.
4. **The live pipeline must not notice.** No changes to publish paths, guardrails, quote-video script assembly, JSON output contracts, or maxTokens values. Additive migration only.
5. **The ingest script writes ONLY to `reference_packs` and `personas.style_brief`.** Never to `topics` or `content_pieces` — anything inserted there gets auto-built and auto-published by the crons.

## 3. Data model — migration `supabase/migrations/024_reference_packs.sql`

## 4. Prompt injection — `src/lib/prompts.ts` only

New private helper, sibling of `buildBrandVoiceBlock` (prompts.ts:24-69):

```ts
const STYLE_BRIEF_MAX_CHARS = 1500;

function buildStyleBriefBlock(persona: Persona): string {
  // Bracket access: DB types may lag migrations (same rationale as buildBrandVoiceBlock, prompts.ts:21-23)
  const p = persona as unknown as Record<string, unknown>;
  const raw = typeof p['style_brief'] === 'string' ? (p['style_brief'] as string).trim() : '';
  if (!raw) return '';
  // Sanitize: straight double quotes coach the model into breaking the JSON-only output contract
  const safe = raw.replace(/"/g, "'").slice(0, STYLE_BRIEF_MAX_CHARS);
  return `NICHE STYLE BRIEF (distilled from top-performing videos in this niche — follow the PATTERNS, never copy wording; if this conflicts with PROVEN WINNERS above, PROVEN WINNERS take precedence):
${safe}`;
}
```

Behavioral requirements:
- Returns `''` (never a header) when the field is null/undefined/empty/whitespace — preserves byte-identical prompts.
- Replaces `"` with `'` and hard-caps at 1500 chars (defense in depth; ingest also caps).
- The precedence sentence resolves the winners-vs-brief conflict risk: our own `topWinners` engagement signal outranks competitor-derived guidance.

Injection sites (and explicit non-sites):

| Builder | Inject? | Where | Why |
|---|---|---|---|
| `buildTopicPrompt` (prompts.ts:134) | **YES** | System prompt, adjacent to `voiceBlock` interpolation (line 164), same `${styleBlock ? `\n${styleBlock}\n` : ''}` shape | Highest leverage: titles + hooks are defined here |
| `buildQuoteTopicPrompt` (prompts.ts:80) | **YES** | System prompt, adjacent to `voiceBlock` (line 90) | Freedom Voices topic/figure selection benefits; without this the quote persona silently misses the feature (early return at line 141) |
| `buildContentPrompt` (prompts.ts:259) | **YES** | **System** prompt, after the `content_guidelines` line (~line 271) | System-side so `regenerate/route.ts:50` (uses only the system half) also benefits; scripts/hooks/thumbnailPrompts are generated here |
| `buildRemixPrompt` (prompts.ts:512) | **YES** | System prompt, adjacent to `voiceBlock` (line 525) | Zero signature change; remixed fields inherit the style |
| `buildQuoteContentPrompt` (prompts.ts:213) | **NO — explicit no-op** | — | Live cron discards its system prompt (content-generator route.ts:152 substitutes `captionsSystem`); quote scripts are verbatim quotes assembled in code — a style brief must never touch them. Leave a one-line comment in the builder stating this decision. |
| `buildNewsletterDraftPrompt`, `buildPodcastScriptPrompt`, `buildCarouselSlidesPrompt`, `buildLectureScriptPrompt` | **NO** | — | Out of v1 scope (video-derived brief; long-form/carousel later) |

No builder signature changes anywhere (all four YES-sites already receive `persona`). No maxTokens changes (brief adds input tokens only; ~1500 chars ≈ ~400 tokens per call — acceptable).

## 5. Ingest script — `src/scripts/build-reference-pack.ts` (local only, never bundled)

Conventions: `ingest-quiz.ts` + `run-fv-week.ts` house style — top doc comment with `Run:` line, inline `argVal` helper, **dry-run by default with `--commit` gate**, raw `@supabase/supabase-js` service-role client (never `src/lib/supabase/server.ts` — it imports `next/headers`), relative imports (`../lib/claude`), `[ok]/[skip]/[WARN]/[ERR]` logging, `main().catch(...)` exit-1, no package.json entry, no dotenv import (env via `--env-file=.env.local`).

```
Run:
  npx tsx --env-file=.env.local src/scripts/build-reference-pack.ts \
    --persona <uuid> --videos <url1,url2,...> [--max 5] [--commit]
```

Pipeline per video (yt-dlp via `node:child_process` `execFileSync` — new ground for the repo, keep it inside this script so the Vercel bundle never sees it; yt-dlp is on Adam's PATH, verified this session):

1. **Metadata**: `yt-dlp --dump-json --skip-download <url>` → id, title, channel, view_count, duration, thumbnail URL. On failure: `[WARN]`, skip video, continue.
2. **Transcript**: `yt-dlp --skip-download --write-auto-sub --sub-lang en --sub-format vtt` to a temp dir (`node:os` tmpdir + `node:fs` cleanup); strip cue timestamps/tags, dedupe consecutive lines (auto-subs repeat), keep first ~4000 chars. Missing subs → `[WARN]`, proceed with metadata only.
3. **Thumbnail vision pass**: download thumbnail bytes (fetch highest-res `i.ytimg.com` variant; note webp is common), send to Claude vision (`claude-haiku-4-5-20251001` per-call override — do NOT touch shared defaults in claude.ts) with a prompt asking for a compact composition description: layout, text treatment, color strategy, facial expression/emotion if present, focal object. → `thumbnail_style_notes`. On failure: `[WARN]`, null.
4. **Upsert** `reference_packs` on `(persona_id, source_video_id)` (idempotent re-runs, mirrors `topic_hash` convention).

Then one **distillation call** over all rows for the persona (including previously ingested ones — re-runs strengthen the brief):

5. `claude.generateStructured` (preferred JSON path per house convention, sonnet default model) with a zod schema — add `referencePackBriefSchema` + inferred type to `src/lib/schemas.ts` (pure zod, safe for both bundles). Distillation prompt requirements: output ≤1500 chars; sections TITLES / HOOKS / STRUCTURE / THUMBNAILS; patterns only, **never quote or paraphrase specific competitor sentences or titles verbatim**; no double quotes; no JSON examples; written as imperative guidance ("Open with...", "Titles pose...").
6. `--commit` → update `personas.style_brief` (and print it); dry-run → print everything, write nothing.
7. Final summary block: videos ingested/skipped, brief length, target persona name, reminder that the brief goes live at the next cron firing once deployed.

Sanity guards: `--persona` must match an existing personas row (print its name for confirmation); refuse `--videos` count > `--max` (default 5); refuse if a video's channel matches the persona's own channels (self-reference is what `topWinners` already covers).

## 6. Tests (additions to `src/lib/prompts.spec.ts`)

1. **Absence invariant (the critical one):** for a persona without `style_brief`, `buildTopicPrompt`/`buildContentPrompt`/`buildRemixPrompt` output is byte-identical to before — assert the block header string does not appear; existing unconfigured-persona assertions must stay green untouched.
2. Presence: brief set → `NICHE STYLE BRIEF` block appears in the system prompt of all four YES-builders (including the quote *topic* builder via a `content_format: 'quote_video'` persona).
3. Sanitization: `"` → `'`; >1500 chars truncated.
4. Whitespace-only brief → treated as absent.
5. Quote content no-op: `buildContentPrompt` for a `quote_video` persona (which delegates to `buildQuoteContentPrompt`) contains NO brief block even when `style_brief` is set.

`vitest run` green + `next lint` clean = implementation gate. (Scripts are excluded from tsc — smoke `build-reference-pack.ts --help`-style dry-run parse by running it without args expecting the usage error path, no network.)

## 7. Risks accepted / mitigated

- **Copyright/brand exposure:** competitor thumbnails are referenced by their original YouTube CDN URLs, never copied into our public `media` bucket (which also rejects webp). Transcript excerpts live in a service-role table, used only as distillation input.
- **JSON contract:** double-quote sanitization at both ingest and injection; brief is prose-only by construction.
- **Cost:** ~400 extra input tokens on 4 call sites; weekly topic call + per-topic content calls ≈ negligible vs. existing spend; no output-cap changes.
- **Winners conflict:** explicit precedence sentence in the block (§4).
- **Stale-types drift:** types updated per CLAUDE.md, but prompts read bracket-style so a types/DB lag can never crash a cron.

## 8. Deferred (v2, separate decision)

- **Image-reference thumbnails:** requires a new Gemini `generateContent` image-model method (Imagen `:predict` cannot take an input image), a new multipart `editImage` on openai.ts, `SlideLadderDeps` widening, cost-tracking updates, and an answer to the audit-fail-closed trap (a competitor reference containing crowds/white subjects would steer HUVA-constrained personas into burning all 4 paid attempts → template fallback every time). v1's `thumbnail_style_notes` → distilled THUMBNAILS section captures most of the value as text.
- Widening to newsletters/carousels/lectures.
- Auto-refresh cadence (re-run ingest monthly as competitor metas shift).
